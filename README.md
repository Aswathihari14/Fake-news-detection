# 📰 Fake News Detection using Machine Learning

This project identifies whether a news article is real or fake using Natural Language Processing (NLP) and Machine Learning.

## 🧠 Tech Stack
- Python  
- Pandas, NumPy  
- Scikit-learn (TF-IDF, PassiveAggressiveClassifier)

## 🚀 Features
- Text preprocessing using TF-IDF  
- Model training and evaluation  
- Custom news text prediction (Real or Fake)

## 🎯 Example Output
"NASA discovers water on the moon" → ✅ Real News  
"Aliens took over the White House" → ❌ Fake News
